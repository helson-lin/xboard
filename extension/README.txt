XBoard Saver 安装与使用
======================

这个扩展做的事：在你浏览 X / Twitter 时，给每条推文的操作栏（回复 / 转发 /
点赞 / 分享 那一行）末尾加一个「归档」图标，点一下就把这条推文推进 XBoard 的
下载队列，不需要复制链接、也不用打开弹窗。

安装
----

1. 在 XBoard 管理台「设置 → 浏览器插件」下载 ZIP 并解压（或直接用仓库里的
   extension/ 目录）。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启「开发者模式」，点「加载已解压的扩展程序」，选中解压出的
   xboard-extension 文件夹。
4. 点工具栏里的扩展图标，填写 XBoard 地址和 API Token（在管理台
   「设置 → 浏览器插件」里复制），点「保存」或先「测试连接」。
5. 刷新 X 页面。

使用
----

- 时间线、搜索结果、推文详情页，每条推文右下角都会多一个归档图标。
- 点图标：转圈（提交中）→ 变绿（已入队）；失败会变红并在右下角弹出原因。
- 右键菜单「保存到 XBoard」仍然可用，适合在链接上直接右键。

图标状态
--------

- 灰色：可保存
- 蓝色转圈：正在提交
- 绿色：已加入下载队列（2 秒后恢复）
- 红色：失败，悬停看原因（未配置 / Token 无效 / 链接无法解析）

常见问题
--------

- 图标没出现：确认扩展已启用，并且刷新了页面（X 是单页应用，装好扩展后
  必须刷新一次）。
- 提示「请先在插件弹窗中配置服务器地址和 API Token」：打开扩展弹窗填好再保存。
- 提示 Token 无效：管理台设置页可轮换 Token，插件里同步更新。
- 自建服务器用自签 HTTPS 时，先在浏览器里打开一次该地址并信任证书。

安全提示
--------

- API Token 等同于写入凭据，请勿分享给不可信的人。
- Token 泄露时可在 XBoard 设置页重新生成，旧 Token 立即失效。
