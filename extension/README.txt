XBoard Saver 安装说明
====================

1. 解压本 ZIP。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 xboard-extension 文件夹。
5. 在 XBoard 管理端“设置 → 浏览器插件”复制 API Token。
6. 打开插件，填写 XBoard 地址和 API Token，点击“保存配置”。

使用方式
--------
- 在任意 X/Twitter 推文详情页点击插件图标，然后加入下载队列。
- 或在推文页面/推文链接上右键，选择“保存到 XBoard”。

安全提示
--------
- API Token 等同于插件访问凭据，请勿分享给不可信的人。
- 若 Token 泄露，可在 XBoard 设置页重新生成；旧 Token 会立即失效。
